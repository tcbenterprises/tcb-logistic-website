## Deploy to GitHub Pages in 2 minutes

### Option 1: Quick (recommended for you)
1. Go to github.com and create NEW repository: `tcb-logistic` (public)
2. Upload the `index.html` file from this folder to the repository root
3. Go to Settings > Pages
4. Under Source, select "Deploy from a branch" -> Branch: main / root -> Save
5. Your site will be live at: https://yourusername.github.io/tcb-logistic/ in ~1 minute

### Option 2: Full repo
1. Create repo `tcb-logistic`
2. Upload ALL files in this folder
3. Enable Pages as above

## Custom Domain (optional)
- If you own tcblogisticenterprises.com, add a file named `CNAME` containing: tcblogisticenterprises.com
- Then point your domain's DNS to GitHub Pages (A records or CNAME)
